🏏 IPL Analysis Dashboard (Power BI)

This project presents an interactive and dynamic analysis of the Indian Premier League (IPL) using Power BI. The dashboard is built using real-world data and provides deep insights into player and team performances across multiple seasons.

📊 Key Features
Interactive and dynamic dashboard
Real IPL dataset (2008–2025)
Player-wise and team-wise performance analysis
Integrated player images for enhanced visualization
Advanced KPIs like total runs, strike rate, economy rate, and win percentage
Filters and slicers for season, team, and player selection
Drill-down and drill-through capabilities
Dynamic titles and tooltips for better insights

🛠️ Tools & Technologies
Power BI Desktop
Power Query (Data Cleaning & Transformation)
DAX (Data Analysis Expressions)
Data Modeling (Star Schema)


📈 Insights Generated
Top batsmen and bowlers analysis
Team performance comparison
Toss impact on match results
Venue-based performance trends
Win/loss patterns and match outcomes
Season-wise performance trends


🚀 Highlights
Fully dynamic dashboard with real-time interaction
Clean and user-friendly UI/UX design
Optimized data model for better performance
Business-oriented insights for sports analytics
